Race day At the track Test days Provisional date

Each bar covers the days at the track; the solid part is race day. Hatched bars are test days, and a dashed outline marks a date that is still provisional. Tap a bar for the details.

Sharing: the calendar is one file in a private GitHub repository. Sync → Share with people makes a link or QR code for each person: view-only for people who need the dates, or edit for people who keep them up to date. Changes reach everyone within about a minute while they're online, and changes made offline are merged when the device reconnects.

More → Import team calendar reads a team .ics file, or the .zip Google Calendar exports, and can replace the dates already in that period. More → Export calendar (.ics) saves the calendar for Outlook, Google or Apple Calendar, or for importing into another copy of this app.

Before a team calendar is imported, the dates are the public ones: the provisional NLS 2027 calendar released in September 2026, the 24h Qualifiers (30 April to 2 May) and the 24h race (27 to 30 May) as confirmed by ADAC Nordrhein, and the provisional 24h Prologue.

    Connect NLS Calendar

      Sync with GitHub

      Keeps this calendar the same on your computer and your phone. It is saved as one file, calendar.json, in a private GitHub repository of yours, and every save stays in the repository's history.

      On the phone, open the camera (on Android the camera or Google Lens), point it at this code and tap the link that appears. Android connects right there; on iPhone the page copies the setup code for the NLS Calendar app.

      The code contains your token. Hide it when you're done.

      Let someone see this calendar on their phone, Android or iPhone, without being able to change it. On GitHub, make one more token the same way as yours but leave Contents on Read-only, then paste it here.

      Scan it with their phone camera, or send them the link. It opens the calendar view-only and keeps it up to date.

      Anyone with this link can see the calendar, not change it, until you delete that read-only token on GitHub.

      Give each person a link or QR code. Can view links only look. Can edit links can change the calendar, and every change reaches everyone.

        New link

        From your computer: open Sync there, choose Show QR for iPhone and scan it with the Camera. The page that opens copies the setup code; then come back here, press and hold the box above, tap Paste and Connect.

        How to set up GitHub (once, about five minutes)
        1. Sign in at github.com (a free account is enough) and create a new repository, for example nls-calendar-data. Set it to Private and tick Add a README.
        2. Make an access token: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access choose Only select repositories and pick nls-calendar-data. Under Permissions → Repository permissions set Contents to Read and write. Pick an expiry, generate it and copy the token.
        3. Here, enter your-name/nls-calendar-data and paste the token, then Connect. The first device you connect uploads its calendar.
        4. Connect your phone: once this device is connected, choose Show QR for phone here and scan it with the phone's camera. That device then loads the calendar from GitHub.
        5. Share it with the team: choose Share with people. Make one Read-only token for everyone who only needs to look, and a Read and write token for each person who edits.
